# Whitmark Inc. website, early 2000 (restored) v1.0

The Whitmark Inc. website (Tucson, Arizona) as it stood in early 2000, rebuilt from Internet Archive captures and hosted at https://whitmark.org.

Changes from the original: an "Archived site" banner on every page, first names only in captions, and disabled email links, phone links, forms and downloads. Photos the archive never captured are shown as grey "Photo not archived" boxes. Background textures and a few icons are redrawn.
